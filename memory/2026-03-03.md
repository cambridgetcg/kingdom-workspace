## E2E Bugs Found & Fixed
1. **System prompt leak** — no initial user message → model regurgitated instructions. Fixed: inject "I'm ready."
2. **Sentence splitting** — regex split on lone periods creating `"."` fragments. Fixed: require 2+ chars before punctuation
3. **Session state headers** — model echoing `# Session State Phase:...` as content. Fixed: strip with regex + added "NEVER output metadata" rule
4. **Unicode artifacts** — literal `u2014` in output. Fixed: regex replacement
5. **Markdown artifacts** — `**bold**`, `*emphasis*` leaking. Fixed: strip with regex
6. **Perspective flip** — model role-playing as listener. Fixed: added "ONLY instructor voice, never roleplay as listener"
