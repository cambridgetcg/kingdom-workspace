## Prompt Engineering Insights
1. "Read these specific files before writing" > vague pattern matching
2. "Verify which handlers are actually implemented" prevents creating broken CLI
3. Sessions self-correct well — let them discover reality
4. Assessment-only tasks find what targeted fixes miss
5. Always include a broad-scan session per round
6. File ownership assertions prevent merge conflicts
7. "Document related issues, don't fix them" feeds next round
8. Test sweep after every round catches regressions
