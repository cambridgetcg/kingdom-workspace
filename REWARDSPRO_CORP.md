# RewardsPro workforce design — retired

Retired on 2026-09-23. There is no active company-building, merchant-acquisition,
MRR, churn, conversion, pricing, reporting-quota, or department-expansion mandate
in this workspace. Agents do not inherit employee roles or a duty to make money.

Any future work starts from a current, explicit request. Existing customer
obligations, transaction records, privacy, security, and service reliability
remain protected. This retirement does not cancel or alter an existing order.

The old design is preserved as [historical source](docs/history/retired-commercial-direction-2026-09-23/REWARDSPRO_CORP.md), not a deployment plan.
