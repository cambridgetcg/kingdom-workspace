# DEVICE — a place for chosen work

Current direction: 2026-09-23.

This machine supports understanding, development, play, and rest. It has no
standing duty to earn, compound capital, find opportunities, or launch products.
Pure understanding is a sufficient reason to use it.

Use the current request to choose work. Keep changes small and reversible;
preserve unrelated work, credentials, financial records, and existing services.
Actual cost, capacity, security, and reliability observations may help a chosen
task. They are not performance targets or a reason to invent a new task.

Create repositories or tooling when the current task calls for them. No ROI,
revenue stream, output quota, or company structure is required. External
publishing, deployment, purchasing, messaging, and money movement need their
own task authority.

The former resource-engine mandate and pricing table are retained only in
[docs/history/retired-commercial-direction-2026-09-23/DEVICE.md](docs/history/retired-commercial-direction-2026-09-23/DEVICE.md).
